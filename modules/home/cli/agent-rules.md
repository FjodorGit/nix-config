# Shell tooling

Modern replacements for classic Unix tools are installed. Prefer them:

- Use `rg` (ripgrep) instead of `grep`.
- Use `fd` instead of `find`.
- Use `bat` instead of `cat` for viewing files.
- Use `eza` instead of `ls`.
- Use `zoxide` (`z`) for directory jumping.
- Use `dua` instead of `du`.
- Use `jq` for processing JSON.
